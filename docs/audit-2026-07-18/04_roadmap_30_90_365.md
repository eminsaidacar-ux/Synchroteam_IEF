- **V1 (mois 4-8)** : planning drag & drop, module astreinte, matching SR semi-automatique, ingestion Gmail server-side (après migration du hub mail sur le domaine), visio auto-hébergée (PeerServer + coturn), 2 premiers agents (triage, facturation/relances) en mode « préparer, jamais envoyer ».
- **Bascule Synchroteam** : après 30 jours d'uptime observé + supervision en place + mode dégradé astreinte testé ; résiliation ensuite seulement.
- **V2 (mois 9-14)** : module achats complet (multi-catalogues, prix historisés, rapprochement fournisseur ↔ ligne client, marge réelle par affaire), agents complets (chiffrage, achats, qualité/audit), maintenance préventive par équipement, portail donneur d'ordre (syndics/hôtels — pas EG).
- Test de réversibilité semestriel (un développeur tiers ou une autre instance reprend le projet en < 1 jour : doc, pg_dump externe, stack mainstream).

**Critères de sortie J+365** : Synchroteam résilié ; marge réelle par affaire visible ; astreinte tracée de l'appel à la facture ; Emin hors du chemin critique quotidien (Accept délégué, validations par exception).
